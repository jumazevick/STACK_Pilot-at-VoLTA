# Data Availability Statement

The anonymised and aggregated data and analysis code supporting this study are publicly available at [https://github.com/jumazevick/STACK_Pilot-at-VoLTA](https://github.com/jumazevick/STACK_Pilot-at-VoLTA). The repository contains aggregate Moodle/STACK activity summaries, question-level performance data, response-status summaries, invalid-input frequency tables, questionnaire summary statistics, selected non-identifying feedback excerpts, figure source data, and scripts for reproducing the public analyses.

Raw student-level Moodle/STACK records, linked Moodle-questionnaire data, and full questionnaire responses are not publicly available because the study involved upper-secondary students and these records may allow participant re-identification, even after pseudonymisation. Access to restricted data may be considered by the corresponding author upon reasonable request, subject to ethical, privacy, institutional, and school-level approval.

If the repository is subsequently archived in Zenodo, replace the GitHub URL above with the DOI URL and retain the GitHub link as the version-control/project link.
