# Paper reproducibility matrix

This table distinguishes numerical outputs that can be regenerated from the public
release from source artwork and analyses that require restricted local inputs.

| Paper item | Content | Reproduction route | Publicly reproducible? |
|---|---|---|---|
| Figure 1 | Example STACK question screenshot | Preserve the original image asset separately | No, source artwork |
| Figure 2 | TAM-derived conceptual framework | Preserve the original diagram asset separately | No, source artwork |
| Figure 3 | Student-response analysis workflow | Preserve the original workflow diagram separately | No, source artwork |
| Figure 4 | Question-level facility index | `plot_public_data.save_facility` | Yes |
| Figure 5 | Question-level response-status summary | `plot_public_data.save_response_status_by_question` | Yes |
| Figure 6 | Invalid-input frequency heatmap | `plot_public_data.save_invalid_input_heatmap` | Yes |
| Figure 7 | Previous experience and device | `plot_public_data.save_questionnaire_background` | Yes |
| Figure 8 | Most difficult topic chart | `plot_public_data.save_most_difficult_topic` | Yes |
| Table 2 | Activity engagement and mean/SD grade | `public_data/activity_summary.csv`; generated by `build_activity_summary` from restricted outputs | Yes, as aggregate data |
| Table 3 | Invalid inputs and expected answers | `scripts/make_table3_invalid_input_examples.py` | Restricted-input reproduction |

Run all public numerical figures with:

```powershell
python scripts/plot_public_data.py
```

Create Table 3 locally, where restricted data are available, with:

```powershell
python scripts/make_table3_invalid_input_examples.py
```

Figures 1–3 are not numerical-analysis outputs. The original high-resolution image
files should be retained as separate manuscript assets because code cannot recreate
the exact screenshot or source diagrams from the aggregate release.
