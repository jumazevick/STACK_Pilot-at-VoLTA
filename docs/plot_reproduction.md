# Plot reproduction guide

All data-driven plots in this release are generated by
[`scripts/plot_public_data.py`](../scripts/plot_public_data.py). The script reads
only aggregate CSV files under `public_data/` and writes PNG files under
`reproduced_figures/`. The output directory is ignored by Git because the images
are reproducible build outputs.

## Reproduce every public plot

From the repository root:

```powershell
python scripts/plot_public_data.py
```

This calls each `save_*` function and creates:

| Function | Input file(s) | Output |
|---|---|---|
| `save_activity` | `public_data/activity_summary.csv` | `activity_mean_grade.png` |
| `save_activity_participation_performance` | `public_data/activity_summary.csv` | `activity_participation_performance.png` |
| `save_facility` | `public_data/figure_source_data/facility_index_by_question.csv` | `question_level_facility_index.png` |
| `save_status` | `public_data/figure_source_data/response_status_by_quiz_and_question_long.csv` | `response_status_summary.png` |
| `save_response_status_by_question` | `public_data/figure_source_data/response_status_by_quiz_and_question_long.csv` | `response_status_by_question.png` |
| `save_invalid_inputs` | `public_data/figure_source_data/invalid_inputs_by_quiz_and_question.csv` | `invalid_input_frequency.png` |
| `save_invalid_input_heatmap` | `public_data/figure_source_data/invalid_inputs_by_quiz_and_question.csv` | `invalid_input_heatmap.png` |
| `save_questionnaire_background_en` | `public_data/questionnaire_summary_counts_percentages.csv` | `questionnaire_background_en.png` |
| `save_questionnaire_background_it` | `public_data/questionnaire_summary_counts_percentages.csv` | `questionnaire_background_it.png` |
| `save_most_difficult_topic` | `public_data/questionnaire_summary_counts_percentages.csv` | `most_difficult_topic.png` |
| `save_reported_difficulties` | `public_data/reported_difficulties_summary.csv` and questionnaire counts | `reported_difficulties.png` |
| `save_appendix_d_survey_results` | `public_data/reported_difficulties_summary.csv` | `appendix_d_survey_results.png` |

## Run one plot from a Python code block

```python
from pathlib import Path
from scripts.plot_public_data import save_invalid_input_heatmap

output_dir = Path("reproduced_figures")
output_dir.mkdir(exist_ok=True)
save_invalid_input_heatmap(output_dir)
```

The same pattern works for any other plotting function:

```python
from scripts.plot_public_data import save_activity_participation_performance

save_activity_participation_performance(Path("reproduced_figures"))
```

## Reproduce the paper-style questionnaire and response plots

```python
from pathlib import Path
from scripts.plot_public_data import (
    save_response_status_by_question,
    save_questionnaire_background_en,
    save_questionnaire_background_it,
    save_most_difficult_topic,
)

output_dir = Path("reproduced_figures")
for make_plot in (
    save_response_status_by_question,
    save_questionnaire_background_en,
    save_questionnaire_background_it,
    save_most_difficult_topic,
):
    make_plot(output_dir)
```

## Restricted analysis outputs

Table 3 is generated separately by
`scripts/make_table3_invalid_input_examples.py`. It requires the restricted
local invalid-response file and writes an ignored manuscript-preparation output:

```powershell
python scripts/make_table3_invalid_input_examples.py
```

Figures 1–3 in the manuscript are source artwork rather than numerical plots:
they are a STACK screenshot, a conceptual framework, and a workflow diagram.
Their original image files should be retained separately for submission.
